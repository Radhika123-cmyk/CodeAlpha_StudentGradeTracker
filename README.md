# CodeAlpha Student Grade Tracker

## 📌 Project Overview

The **Student Grade Tracker** is a Java-based desktop application developed as part of the **CodeAlpha Internship**.

The application provides a graphical user interface (GUI) for managing student marks and generating academic performance reports. It allows users to enter student details, record marks for different subjects, and automatically calculate total marks, percentage, and grades.

---

## 🎯 Objectives

- Manage student academic records efficiently.
- Enter and validate marks for multiple subjects.
- Calculate total marks automatically.
- Calculate student percentage.
- Assign grades based on percentage.
- Display average, highest, and lowest scores.
- Provide a simple and user-friendly graphical interface.

---

## ✨ Features

- 🧑‍🎓 Add student details
- 📝 Enter marks for multiple subjects
- 📊 Automatically calculate total marks
- 📈 Calculate percentage
- 🏆 Automatic grade calculation
- 🔍 Validate student and marks input
- 🗑️ Delete selected student records
- 🧹 Clear input fields
- 📋 Display student records in a table
- 📊 Generate performance statistics
- 📄 Display summary report
- 🚫 Prevent duplicate roll numbers
- 💻 User-friendly Java Swing GUI
